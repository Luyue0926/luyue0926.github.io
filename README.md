# Luyue He's Homepage

个人主页，基于 [Academic Pages](https://github.com/academicpages/academicpages.github.io) 模板构建，托管于 GitHub Pages。

- 线上地址：https://luyue0926.github.io
- 自我介绍：`_pages/about.md`
- 站点配置（姓名、邮箱、侧边栏信息、头像文件名）：`_config.yml`
- 导航栏菜单：`_data/navigation.yml`
- 头像图片：`images/profile.jpg`（替换成自己的照片即可）

## 常用操作

本地改完内容后执行：

```bash
git add .
git commit -m "更新内容"
git push
```

推送后 1~2 分钟，网站自动更新。
